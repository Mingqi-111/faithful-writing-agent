# 保义改写 Agent · 宿主版 0.2

导入一次，以后直接在 Codex、Claude Code、WorkBuddy 等应用里发文章。改写使用应用本身的模型，无需为这个 Agent 另外配置 API Key、启动网页或运行常驻服务。仍使用宿主账号额度和工具权限。

Skill 是安装载体；随包分发的程序负责状态、检查、反馈、评测及版本门槛。内容生成和语义审校由宿主执行。

## 最快开始

先从 [v0.2.0 发布页](https://github.com/Mingqi-111/faithful-writing-agent/releases/tag/v0.2.0) 下载附件 **faithful-writing-agent.zip**。它只有一个同名技能目录，可用于支持 ZIP 的技能导入入口。源码下载包用于查看或开发；使用安装脚本时，无论源码目录是否带 `-main`，目标技能名都固定为 `faithful-writing-agent`。

把这个包交给 Codex 或 Claude Code，发：

> 请把 faithful-writing-agent 安装到当前写作项目。以后我发文章时，用它保留原意地改写，反馈和偏好保存在这个项目中，不配置独立 API，也不启动网页。

宿主可执行包内的项目安装脚本。手动安装时，把整个技能文件夹放进对应位置：

| 应用 | 安装位置 / 入口 | 本版状态 |
|---|---|---|
| Codex | 项目 `.agents/skills/faithful-writing-agent/` | 本地状态机可运行；提供本次验证记录 |
| Claude Code | 项目 `.claude/skills/faithful-writing-agent/` | 按官方接口适配，未在 Claude 实机验收 |
| WorkBuddy | 技能 → 添加技能 → 上传技能；或项目 `.codebuddy/skills/` | 官方支持入口，未在 WorkBuddy 实机验收 |
| Claude 普通聊天 | Customize → Skills → 上传 ZIP，并启用代码执行 | 会话内可执行；精确记忆跨会话需导出/恢复 |
| 扣子 / Coze | 桌面端添加本地技能目录；或上传技能后由平台打包部署 | 已核实官方入口，需验证代码环境和状态保存 |

详见 [平台接入说明及官方来源](references/platforms.md)。一个 ZIP 不会自动获得所有应用的权限，也不意味着各平台的长期记忆完全相同。桌面/编程环境通常更适合这个带状态的版本。

安装后，正常使用只需要：

> 改写这篇抖音科技口播，意思不要变：……

没有指定场景时，保留原文文体。已自然的文本可以保持不变。首次无需历史作品，五类预设为通用文章、抖音科技、小红书、客服与演讲稿。

## 反馈也用自然语言

> 这版采用了。

> 我最终改成下面这样，请记录这次修改：……

> 根据已经记录的反馈，评测是否可以改进我的科技口播偏好。

> 启用通过验证的候选。／回退到上一版。

应用会在后台调用本地脚本，不需要用户填 JSON 或输入这些内部命令。只有明确反馈才记作证据；保存、复制或不回复都不自动等于喜欢。

同一用户和场景积累至少 6 篇不同原文的采用反馈后，较早记录用于提取偏好，最后 3 篇留作比较。每条候选偏好须有至少 3 条训练证据。候选通过固定用例和保留稿检查后才可启用；全平局不算改进，内容错误不能靠风格评分抵消。

没有独立审校能力时标记自审；这不等于独立 benchmark，不能默认自动升级。工具也无法仅凭 JSON 证明审稿人独立，因此保留实际执行方式和记录，便于复核。用户可以明确选择降级门槛，但宿主不能替用户选择。

## Benchmark 保留了什么

用户直接说“运行离线检查”或“用当前应用跑 3 个真实 benchmark 用例”，宿主即可执行。当前包含 40 条确定性规则样本和 20 条真实改写开发用例，覆盖误改、内容保留和表达改善。

每篇先保存改稿，再提交语义评审；脚本将数字、链接、代码、引语等差异和实际审校结果合并。最多三份候选，未通过则回退原文。

通用 benchmark 要求每条生成任务完成，缺失记录不会算通过；个性化 benchmark 比较旧策略和候选策略，保存成对输出与审评。没有调用外部模型 API，生成与判断都由当前宿主的模型执行。自审和另一个上下文审查会被区分记录。详见 [评测协议](references/benchmark.md)。

小样本与模型审评不能证明长期收益。规则不会因为模型想提高通过率就自行修改；新的失败模式应成为待审阅案例，再更新公开开发集。

## 文件和数据

```text
faithful-writing-agent/
├── SKILL.md                 宿主入口与行为流程
├── agents/openai.yaml       Codex 展示和触发配置
├── scripts/agent.py         无网络的状态机命令
├── scripts/runtime/         检查、记录与评测门槛
├── scripts/install.py       可选的项目安装器
├── references/              编辑、场景、审校、优化与平台协议
├── benchmarks/              固定检查器样本与真实改写用例
├── tests/                   程序行为测试
└── licenses/                上游归因与许可
```

Python 3.11+ 标准库即可执行，无 pip 依赖。优先使用宿主自带代码环境；用户不必运行一个网页服务。若宿主完全没有代码/文件能力，则只提供基础改稿和自审，不能假称完整 benchmark 和长期反馈已经运行。

状态保存在**写作工作目录**的 `.faithful-writing-agent/`，不写进技能安装目录，不会随重新安装而自动覆盖。持续写同一系列内容时使用同一项目；换新项目不会自动携带旧画像。

文章、候选与反馈属于个人数据，默认保存在该工作目录；模型读取这些内容时受宿主平台的数据政策约束。本包没有额外网络上传。临时沙箱需要把状态文件下载保存并在下一会话恢复，不能承诺无感长期保存。不要把状态目录连同技能包分享给其他人。

本仓库分发宿主版；此前的独立 API 网页原型未包含在此仓库中。

测试方式和实测边界见 [验证记录](VALIDATION.md)；上游依据见 [来源与许可证](THIRD_PARTY_NOTICES.md)。
