## 自查修复的学习问题

1. 全 off 材料不能验证未生效的去模板偏好；现在每个变更键必须在同场景、获准模式下有实际评测覆盖。
2. 两组有效偏好相同的随机措辞差异不得算候选收益，现在强制计为平局，内容错误仍单独检查。
3. 更换宿主后，候选保留的旧偏好也必须重新覆盖。评测基线和正常生成采用相同有效性判断。
4. 规则升级后，旧画像必须暂停应用。生成与 A/B 基线共用宿主及候选/报告指纹检查；规则过期时可提交同值候选重验，旧记录不删除。

均有程序回归，包括自审降级不能绕过缺项、历史偏好不能自动升级模式，以及规则升级后完整重验才能恢复。没有虚构真实用户反馈来宣称个性化质量改善。

## 语料及公开边界

方法见 [RESEARCH.md](../RESEARCH.md)，逐篇来源见 [索引](corpus/INDEX.md)。100 篇媒体均做模型片段阅读，其中 12 篇全文阅读；85 篇 AI 来源文章均全文及提示审查，人工审读 0 篇。另一上下文核对了元数据、原始 CSV 定位、哈希、选择一致性和公开内容边界，不将数据核对包装成第二轮全文质量标注。

## 复核命令

在包目录执行：

```bash
python3 -m unittest discover -s tests -v
python3 -I scripts/agent.py doctor
python3 -I scripts/agent.py benchmark --mode offline
```

真实生成需宿主按 SKILL.md 和 references/benchmark.md 完成 prepare → 逐篇 draft/review → report，脚本不会暗中调用模型 API。重复 `--case` 可选择公开开发用例，不能裁剪个性化门槛。
