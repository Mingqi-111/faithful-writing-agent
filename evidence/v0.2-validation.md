终稿：

> 这次更新新增了离线搜索，可以在离线时搜索本地文件。目前还在小范围测试，是否向所有用户开放还没有确定。

本例去掉了重复引入，保留本地文件范围、小范围测试和开放不确定性。它是一个可检查的编辑结果，不是“无法被识别为 AI”的证明。

## 复核程序

在包目录执行：

```bash
python3 -m unittest discover -s tests -v
python3 scripts/agent.py doctor
python3 scripts/agent.py benchmark --mode offline
```

真实生成不能只运行一条脚本就完成。让宿主按 SKILL.md 和 references/benchmark.md 执行 prepare → 每篇 draft/review → report；脚本不会暗中替用户调用模型 API。
